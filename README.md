# Pellucidity

Pellucidity (`skin.pellucidity`) is a modified version of Chris Bevans [Pellucid](https://github.com/chrisbevan/skin.pellucid) skin for Kodi Media Centre.

Built for the living room, Pellucid is a clean and carefully designed Kodi experience designed for maximum usability and minimum fuss. This mod builds on it with a few changes of its own.

It installs as a separate addon, so it can sit alongside the original Pellucid skin.

#### Features

- Skin Shortcuts addon support.
- Full PVR / Live TV support.
- Quick-jump letter list in place of the scrollbar in library views.
- Reworked home screen and weather screens.
- Opening a folder selects its first content item instead of the parent entry, while preserving remembered content selections.
- Simplified XML stack.
- Add custom home screen rotation to overcome Kodis built in "feature" that restarts the image rotation from image #1 on every return to home.

#### Installation

Download the repository as a zip and install it via *Add-ons > Install from zip file*. The folder inside the zip must be named `skin.pellucidity` (GitHub's own downloads name it `skin.pellucidity-<branch>`, so rename it and re-zip it first).

Requires the `script.skinshortcuts` addon.
